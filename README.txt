CUP2EAT static demo website

Files:
- index.html: website structure
- style.css: design and responsive layout
- script.js: demo product catalogue, filters, cart and WhatsApp checkout

To publish on GitHub Pages:
1. Create a public GitHub repository named cup2eat.
2. Upload these four files to the repository root (not inside another nested folder).
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select main branch and /(root), then Save.
6. Wait for the published URL shown in the Pages section.

Before showing the client:
- Confirm product names, prices, images and flavours.
- Replace the demo WhatsApp number 919818192575 in script.js and index.html with the client's approved number.
- Replace placeholder email and contact details in index.html.

Note: This is a front-end demo. Login is not real account authentication, and the cart is stored only in the visitor's browser. For real orders, secure customer accounts, payments, inventory and admin order management, connect WooCommerce or a backend.
